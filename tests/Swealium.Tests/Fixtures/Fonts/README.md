# Font fixtures

`SwealiumTestVariable.ttf` is generated by `tools/generate_font_fixtures.py` from original geometric outlines. It contains a `wght` axis plus deterministic `kern`, `liga`, `ss01`, `tnum` and language-specific `locl` features for cross-platform tests. `SwealiumTestCollection.ttc` contains the two static master faces. These are test assets, not user-facing typefaces. The generator requires fonttools; test execution uses the committed binaries without Python dependencies.

The test output also receives the user-provided `samples/Swealium.Sample/Aldo.ttf` through a linked build item. Its source remains in the sample project.
